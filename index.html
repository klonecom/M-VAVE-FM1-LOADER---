How to use this utility

01

Initialize Web MIDI

Click "Initialize Web MIDI" and allow the browser's SysEx permission prompt. This requires Chrome or Edge — Web MIDI with SysEx access isn't supported in Safari or Firefox.

02

Confirm the output port

The FM-1 is detected and selected automatically when its name is visible to the system. If it isn't picked up, choose it manually from the output dropdown. The status dot turns green once a port is linked.

03

Load a bank file

Drag a .syx file onto the patch bank field, or select one manually. The utility checks for standard exclusive framing (F0…F7) and flags anything unusual before you send it.

04

Send to hardware

Press "Send Bank To Hardware" to stream the file over MIDI. The FM-1 cannot confirm receipt or output SysEx of its own, so once the transfer completes, assign the destination slot directly on the unit to store it.

Note — this utility is transmit-only. The FM-1 has no SysEx dump/output capability, so there is no way to read a bank back from the hardware into this tool.
